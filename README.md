# Roblox Space

A Windows desktop application built in C17. It opens a configured Duo workspace and displays it through a bundled portable Moonlight viewer.

## Download

- [Windows installer](https://github.com/jasonhome-344423/roblox-space/releases/latest/download/RobloxSpace-Setup.exe)
- [Installation guide in English and Chinese](https://github.com/jasonhome-344423/roblox-space/releases/latest/download/Installation-Guide.html)
- [SHA-256 checksums](https://github.com/jasonhome-344423/roblox-space/releases/latest/download/SHA256SUMS.txt)
- [Third-party license and source materials](https://github.com/jasonhome-344423/roblox-space/releases/latest/download/Third-Party-Notices.zip)

On a new Windows installation, follow the guide to install Duo, configure the workspace, and pair the viewer. If you already use Roblox Space, close it and install to the same folder to keep your pairing and notification settings.

Use the controls below the game view to monitor the connection, select a screenshot point, toggle automatic clicking with **F6**, or use the keyboard. Click **X** to close the app, the workspace game, the monitor, Moonlight, and Duo.
