先看：安装 Windows 前保存什么

  1. 把整个源码备份 ZIP 放到 U 盘、外接硬盘或确认上传完成的云盘。不要只放在准备格式化的硬盘。
  2. 在自己的密码管理器保存：Roblox 登录方式、Telegram 登录方式、机器人用户名和完整 Bot Token、Healthchecks 登录方式、完整 Ping URL、完整项目读写 API Key。
  3. 现有程序“通知设置”里的“复制 API Key”可把本机完整 Key 复制出来。网页上掩码的星号不是密钥。
  4. 在 Healthchecks 网页暂停旧电脑的“Roblox 空间”检查，避免安装期间一直报警。
源码 ZIP 不含真实密码、Token、API Key、聊天编号或 Moonlight 配对私钥。旧 mobile-settings.dat 与 Windows 账户加密绑定，安装新系统后不能保证直接复制就能恢复；手机通知按 D 节重新绑定。

安装本程序不需要 Visual Studio、Python、Java 或打包工具。源码重建使用 Windows 11 自带的 .NET Framework 编译器。

独立安装 EXE 已包含 Moonlight 便携组件，不用另装 Moonlight 安装版。Duo 和 Roblox Player 仍需在新系统按 B 节从官网安装；已有电脑升级时继续使用原组件，不需要重复安装。

A　本机升级：原来的空间仍然可用

A1　关闭当前空间，找到安装 EXE

  1. 按当前空间右上角 X，等游戏、监测器与画面退出。安装器遇到仍在运行的空间时，会提示先退出。
  2. 找到本次交付的 RobloxSpace-Setup.exe。它可以独立运行，不必先解压源码备份。
  3. 如果安装 EXE 放在 ZIP 中，先把 EXE 解压到普通文件夹再运行。

完成标志：当前空间已退出，安装 EXE 已保存在普通文件夹。

A2　安装本次正式版

  1. 双击 RobloxSpace-Setup.exe，按向导选择安装位置并点“安装”。默认目录为 %LOCALAPPDATA%\Programs\RobloxSpace。
  2. 升级时继续使用原来的安装目录。安装完成后保留桌面入口 Roblox Space。
  3. 同一个 Windows 用户升级时，程序尝试迁移原 Beta 配置；已经存在的正式版配对和通知资料会保留。
  4. 已有空间能正常使用时，直接打开程序确认。只有缺少配置时才打开“首次配置”，点“重新检查”；不要重复建账户、改密码或安装 Duo。

完成标志：安装向导完成，桌面入口能打开现有空间，通知设置仍在。

A3　打开并确认

  1. 从桌面 Roblox Space 启动，Windows 权限确认选“是”。
  2. 等待画面接入。已有绑定时，顶部显示“手机提醒 · 已开启”和“断网提醒 · 已开启”。
  3. 进入游戏，重新截图选点，再按 F6。迁移不成功时保留旧资料，按 D 节重新绑定。

完成标志：画面可操作、通知状态正常。日常按 C 节使用。

B　新 Windows：按 B1 → B7 完成

B1　准备系统

  1. 使用 Windows 11 64 位。按 Win＋R，输入 winver。Duo 1.6.0 最低要求为 Windows 11 24H2。
  2. 完成 Windows 更新与显卡驱动安装。
  3. 打开“Windows 安全中心 → 设备安全性 → 内核隔离详细信息”，开启内存完整性。需要重启时先保存工作，重启回来确认已开启。
沿用本机已验证设置：内存完整性开启、Process Patching 关闭、HDR 关闭。本机之前出现过与 Duo 内核补丁吻合的蓝屏，不要为 HDR 或高帧率关闭这些保护。

完成标志：系统符合要求，内存完整性正在运行，电脑插电。

B2　运行独立安装程序

  1. 把 RobloxSpace-Setup.exe 保存在普通文件夹，双击运行。
  2. 按向导完成安装。默认安装到当前用户的 %LOCALAPPDATA%\Programs\RobloxSpace，不需要自己复制 DLL。
  3. 安装结束时打开“首次配置”。以后也可从开始菜单“Roblox 空间 → 首次配置”打开。

完成标志：桌面有 Roblox Space，首次配置窗口能打开。继续完成 B3 → B7。

B3　安装 Duo

  1. 在首次配置点“打开 Duo 下载页”，或打开 Duo 1.6.0 官方发布页。
  2. 展开 Assets，下载 Duo.exe，运行并按安装向导完成。
  3. 如果要求重启，保存其他工作后自行完成，再打开首次配置。
  4. 打开 Duo Manager 的设置，关闭 Process Patching，HDR 也保持关闭。

完成标志：首次配置能找到 Duo，Process Patching 关闭。

B4　配置账户、权限和监测任务

  1. 点“配置账户和监测任务”，Windows 权限确认选“是”。
  2. 没有空间账户时，会弹出密码窗口。为 RobloxSpaceBeta 输入两次相同的非空密码并保存，稍后填到 Duo。
  3. 脚本会创建标准账户、配置运行目录权限、部署监测器，并创建计划任务；不会启动游戏。
  4. 看到“配置完成”，回到首次配置点“重新检查”。
正式版继续用内部账户名 RobloxSpaceBeta、Duo 实例名 RobloxBeta，用于兼容已有空间。这不代表安装了另一个 Beta。脚本读取新系统实际 SID，不需要旧电脑 SID，也不会重置已有密码。

完成标志：显示账户、权限和监测任务已配置。若同名任务身份不符，先看 G 节。

B5　建立 Duo 工作区

  1. 点“打开 Duo Manager”。如果已有正确的 RobloxBeta，继续使用。
  2. 新系统点 New instance，按表填写。账户密码使用 B4 保存的密码。
  3. 保存并启动实例。按需要开启 Duo 随 Windows 启动与实例 Auto Start；本程序不会因插电自动重开。

完成标志：RobloxBeta 已启动，字段和表格一致。

B6　Moonlight 配对

  1. 在 Duo 的 RobloxBeta 实例上点 Pair New Client。
  2. 回到首次配置，点“打开 Moonlight 配对”。它会使用正确的专用工作目录。
  3. 在 Moonlight 点添加电脑（＋），填 127.0.0.1:62461。
  4. 点找到的 RobloxBeta，读取本次 PIN，输入 Duo 的配对页面并提交。
  5. 配对成功后，在 Moonlight 打开 Desktop，完成空间里 Windows 的首次登录设置，直到看到新桌面。
  6. 测试鼠标、键盘；完成后关闭临时 Moonlight 窗口，回首次配置点“重新检查”。
从“首次配置 → 打开 Moonlight 配对”进入。不要从其他目录随便双击 Moonlight.exe，否则可能再次提示 has not been paired。每次使用当次 PIN，不能抄旧数字。

完成标志：Moonlight 能打开 Desktop，首次配置找到了配对文件。

B7　在空间内安装 Roblox

  1. 在空间桌面打开浏览器，进入 Roblox 官网，手动登录。
  2. 选择游戏，按官网流程安装 Roblox Player。安装和登录都要在空间账户的桌面内完成。
  3. 测试鼠标、WASD 和聊天。主桌面安装过 Roblox 不等于空间账户也装好。
  4. 回主桌面，关闭临时 Moonlight 窗口，从桌面 Roblox Space 或首次配置“打开 Roblox 空间”启动。
  5. 权限确认选“是”，等待画面接入。第一次建立会比日常启动慢。

完成标志：游戏显示在正式版空间窗口中，可以手动操作。接着按 C 节使用，需要手机通知则做 D 节。

C　日常操作和普通重启

语言切换：在主窗口右上角选择“华语”或“English”，界面立即切换，不需要重启空间；下次打开会记住选择。首次配置和安装程序也有语言选择。通知设置、更新窗口、点击状态和提醒文字随应用语言变化；Roblox 游戏和 Windows 的语言由各自设置决定。
  1. 电脑保持插电。双击桌面 Roblox Space，权限确认选“是”。
  2. 等待画面，进入游戏。
  3. 点“截图选位置”，在截图中选安全位置并确认，不限定聊天按钮。
  4. 按 F6 开启／停止点击，频率每秒一次。每次新启动后重新确认选点。
  5. 要用游戏键盘，先按 F6 停止点击，再点“键盘输入”。
  6. 最小化继续运行；右上角 X 完整退出游戏、点击、监测、画面和程序。
切到电池完整退出，接回电源不自动重开。以后想用时自行双击正式版图标，一次只开一套空间。

普通重启后按本节启动。Windows 和账户没换时，不用重新建立账户、配对或绑定机器人。

卸载本程序时，在 Windows“设置 → 应用 → 已安装的应用”找到 Roblox 空间，选择卸载。正常卸载保留配对、通知资料及单独安装的 Duo、Roblox；安装新 Windows 后仍按本说明重新配置。

D　手机通知：两部分都要做

D1　自己的 Telegram 机器人

  1. 在 Telegram 打开官方 @BotFather。已有机器人用 /mybots 查看；需要新建才用 /newbot，按提示填名称和以 bot 结尾的用户名。
  2. 复制完整 Bot Token，只粘贴到本机设置，不发到聊天或本说明。
  3. 在空间点“通知设置”，粘贴 Token →“1. 连接机器人”。
  4. 在打开的本次绑定链接里点 Start。链接有绑定码，只打开旧聊天不能替代。
  5. 回设置点“2. 完成绑定”→“发测试到手机”。确认收到了，再点保存并启用。
  6. 资料齐全后每次启动自动开启，不用再勾选。

完成标志：自己的机器人发来测试消息，主窗口显示手机提醒已开启。

D2　完全断网的 Healthchecks 云端提醒

电脑断网后不能自行立刻发消息，所以云端检测心跳中断并通知手机。它和 D1 是两套渠道。

  1. 登录 Healthchecks.io。已有“Roblox 空间”检查就继续使用；没有才创建。
  2. 类型选 Simple。Period＝1 分钟，Grace Time＝1 分钟，保存并确认两个值。
  3. 过滤规则里，暂停检查收到心跳时允许自动恢复，Manual Resume 关闭。
  4. 在项目 Integrations → Telegram 连接：Telegram 打开 @HealthchecksBot → Start → 点它回复的链接 → 选当前项目 → Connect Telegram。
  5. 回到“Roblox 空间”检查，确认它启用了这个 Telegram 渠道。只连接项目但没分配给检查仍不行。
  6. 复制完整 Ping URL，形如 https://hc-ping.com/一串UUID。
  7. 在项目 Settings → API Access 获取读写 API Key。不是只读 Key，也不是 Bot Token。完整 Key 如果只显示一次，立即保存到自己的密码管理器。
  8. 在本程序“通知设置”填写 Ping URL 和 API Key →“验证云端设置”→ 成功后保存并启用。
程序约每 30 秒发心跳；云端从最后一次收到心跳计算约 2 分钟，不等待 Roblox 掉线。界面是预计倒计时，不保证手机精确在零秒弹出。

D3　怎样做真实断网测试

  1. 程序保持打开、电脑保持插电。不要点 X，正常退出会尝试暂停云端检查。
  2. 手机关闭 Wi-Fi、开启移动数据，确认 Telegram 能联网。
  3. 只断开电脑网络，持续 3 分钟，查看 HealthchecksBot 的 DOWN。
  4. 恢复网络，查看 UP；自己的机器人排队消息也会恢复重试。

完成标志：HealthchecksBot 收到 DOWN／UP。拔电源会退出程序，电池退出测试要与断网测试分开。

E　软件更新与新版提醒

“软件更新”负责升级 Roblox 空间程序本身；“通知设置”里的 Telegram／Healthchecks 负责电脑供电、网络和游戏掉线。先看清入口，再按相应步骤操作。

版本从 1.0.0 开始：第一位为大更新，第二位为小更新，第三位为修复或补丁。更新功能按安装内容识别不同的更新包。公开更新清单为 https://raw.githubusercontent.com/jasonhome-344423/roblox-space/main/latest.json。新安装会自动填入；旧安装可以按 E2 保存这个地址。

E1　查看当前更新状态

  1. 在主窗口打开软件更新。窗口标题为“软件更新 · Roblox 空间”。
  2. 看状态文字。如果显示未设置更新地址，表示还没有可检查的发布源；这时可以使用 E3 的本地安装包方式。
  3. “检查更新”只检查安装内容是否有更新，不会直接关闭游戏。

完成标志：知道现在是未配置、检查中、已是当前内容，还是发现可用更新；没有把“未配置”当成已联网检查。

E2　发布后开启自动检查和提醒

  1. 复制官方更新清单地址：https://raw.githubusercontent.com/jasonhome-344423/roblox-space/main/latest.json。它应是可读取的 HTTPS JSON 清单地址，不是仓库首页或安装 EXE 的下载地址。
  2. 在软件更新窗口，把地址粘贴到“更新清单地址（HTTPS）”。
  3. 勾选“自动检查更新并提醒”，点保存设置。
  4. 点检查更新，确认能读取清单。发现不同的可用安装内容时，程序会显示“发现可用更新”；程序运行期间会按后台检查间隔继续检查。
  5. 收到提醒后，由你决定何时安装。只检查、关闭提醒或继续游戏都不会自动开始安装。

完成标志：地址保存成功，手动检查可正常读取清单；不再显示“未设置更新地址”。

E3　没有发布地址时，选择本地安装包更新

  1. 把同一次交付的 RobloxSpace-Setup.exe 与 RobloxSpace-Setup.exe.update.json 放在同一个普通文件夹。
  2. 在软件更新窗口点选择本地安装包，选择这个 EXE。
  3. 程序会核对配套清单。如果没有自动找到，会提示你选择对应 JSON；此时选择同批次的 .update.json。
  4. 看到可用更新后，再点下载并安装更新，按确认提示继续。本地包无需再次从网上下载。
直接双击安装 EXE 可以独立安装；只有在“软件更新”里选择本地更新包时，才需要对应的校验 JSON。请保留同批次两个文件，不要混用旧清单和新 EXE。

完成标志：EXE 与清单校验通过，程序能显示这份安装包是否与当前安装内容不同。

E4　确认后安装，完成后重新选点

  1. 确认当前游戏可以退出，再点下载并安装更新。
  2. 联网更新会下载并验证安装包。需要中止下载时，点取消下载。
  3. 验证通过、你确认安装后，程序会先完整退出游戏、监测和画面，再运行安装器。安装器遇到仍在运行的空间时会提示处理。
  4. 继续使用原安装目录完成安装。配对和手机通知保存在独立用户资料目录，正常覆盖升级会保留它们。
  5. 安装完成后打开桌面 Roblox Space，检查画面和通知状态，再重新截图选点、按 F6 开启点击。

完成标志：安装完成，正式版可启动；已有配对和通知仍在，新的点击选点已确认。

自动检查和软件新版提醒需要程序保持运行，并有有效的更新清单地址。切到电池或按 X 退出后，本程序不会继续检查软件更新。手机端仍需按 D 节单独配置游戏与断网通知。

F　从源码重建与备用恢复

  1. 保留完整解压目录，不要只取几个源文件。
  2. 关闭所有空间版本，双击 重建程序.cmd。
  3. 等待编译、C# 检查和 PowerShell 检查。可能出现短暂测试窗口；保持主桌面，不要同时输入游戏。
  4. 成功后会更新 app、校验清单，并在 outputs\安装程序 生成安装 EXE；双击该 EXE 安装。

G　问题对照与验收

提示 has not been paired

关闭空间和临时 Moonlight。通过首次配置的配对按钮按 B6 重配，使用当次 PIN 和专用工作目录。不要随便删证书或关闭安全功能。

没有空间画面／启动未完成

确认插电，Duo 的 RobloxBeta 正在运行、账户密码正确、端口 62461。Process Patching 与 HDR 关闭，内存完整性开启。先测试 Moonlight 能打开 Desktop，再启动本程序；用首次配置的“重新检查”定位缺少的步骤。

拒绝访问／监测器没启动／任务不存在

完整退出后，运行首次配置的“配置账户和监测任务”并确认 UAC。它使用当前 SID。任务名 Codex-RobloxSpace-Worker；账户 RobloxSpaceBeta；交互登录、普通权限；程序 C:\ProgramData\RobloxSpace\RobloxSpaceWorker.exe；参数 --start-monitor；没有计划触发器，不勾最高权限。已有任务身份不同会拒绝覆盖，先核对，不删无关任务。

点击或键盘无反应

确认已进入游戏、监测开启、截图选点确认。点击区显示实际阻塞原因。打字前按 F6 停止点击，再点键盘输入。分辨率变化后重新选点；旧位置不会盲目继续。

手机没消息

确认程序运行、顶部状态正常、手机有网络并允许 Telegram 通知。日常测试看自己的机器人；完全断网看 HealthchecksBot。保持断网 3 分钟，不要用关闭程序代替断网测试。渠道异常时核对 Telegram 已分配给这个检查。

安装或更新提示程序仍在运行

按空间右上角 X，等待游戏、监测器和画面全部退出，再回安装器继续。不要把最小化当作退出。如果是软件内安装更新，先等退出流程完成；看到残留或权限错误时按具体提示处理。

软件更新显示未设置地址／无法检查

未填写 HTTPS 更新清单地址时，无法联网检查新版。按 E2 保存官方 JSON 地址。网络失败时保留当前程序，可稍后重试或按 E3 选本地包；这与 Healthchecks API Key 无关。

本地更新缺少 JSON／安装包校验失败

保留同批次 EXE 与 <安装器文件名>.update.json，按 E3 选择。校验失败时重新取得完整的一组文件，不跳过检查，也不混用旧清单。

备用恢复脚本提示目录或校验错误

使用默认独立安装目录，先完整解压源码备份。脚本不会覆盖没有本产品标记的非空目录，也不能安装到磁盘根目录或备份包本身。文件校验失败时重新完整解压，不跳过验证。

蓝屏

保留停止代码和转储文件，暂停启动 Duo。保持内存完整性开启、Process Patching 与 HDR 关闭，核对组件与显卡驱动；不能只凭界面判定唯一原因。

A. Upgrade an existing installation

  1. Close the current workspace using its X button. Wait for the game, monitor, and viewer to exit. The installer refuses to overwrite a running workspace.
  2. Save RobloxSpace-Setup.exe in a normal folder. If it is inside a ZIP file, extract it first.
  3. Run the EXE. Keep the existing installation directory. The default is %LOCALAPPDATA%\Programs\RobloxSpace.
  4. Complete the installer. Existing pairing and notification settings are stored separately and are retained. Same-user legacy migration does not overwrite existing current settings.
  5. Open the desktop Roblox Space shortcut. Approve a Windows permission prompt if one appears.
  6. Confirm the workspace picture and notification status. Enter the game and choose a new click position before pressing F6.

If the existing workspace works, continue using it. Do not create another Windows account or reinstall Duo just for an application upgrade. Use First Setup only when setup is incomplete.

Complete when the desktop shortcut opens the workspace and existing notification settings remain available.

B. Set up a new Windows installation

B1. Prepare Windows

  1. Use Windows 11 64-bit, 24H2 or later. Press Win+R, enter winver, and check the release.
  2. Finish Windows updates and install the graphics driver.
  3. Open Windows Security, Device security, Core isolation details. Enable Memory integrity. If Windows requests a restart, save your work, restart, and confirm the setting.
  4. Keep Process Patching off in Duo and keep HDR off for this configuration.

B2. Install Roblox Space

  1. Run RobloxSpace-Setup.exe and complete the installer.
  2. Leave the desktop and Start menu shortcuts enabled.
  3. Open First Setup at the end of installation, or from the Roblox Space group in the Start menu.

The installer includes the application and portable Moonlight runtime. You do not need Visual Studio, Python, Java, or an external packaging compiler to install it.

B3. Install Duo

  1. Use First Setup's Duo download button or the official Duo 1.6.0 release page.
  2. Expand Assets and download the official Duo.exe. Run it and finish installation.
  3. If a restart is required, save your work and restart manually, then reopen First Setup.
  4. In Duo Manager settings, switch Process Patching off and leave HDR off.

B4. Create the workspace account and monitoring task

  1. In First Setup, choose the action that configures the account and monitoring task. Approve the Windows administrator prompt.
  2. If the account does not exist, enter and confirm a nonempty password for RobloxSpaceBeta. Save it securely for the next step.
  3. The setup creates a standard account, sets runtime permissions, deploys the monitor, and registers its task. It does not start the game.
  4. Wait for completion, then use the recheck button.
The internal account name RobloxSpaceBeta and Duo instance name RobloxBeta are retained for compatibility. Existing account passwords are not reset. New installations use the account SID from that computer.

B5. Configure a Duo workspace

B6. Pair Moonlight

  4. Test manual clicking, WASD movement, and chat typing.
  5. Return to the main desktop, close the temporary Moonlight window, and open the desktop Roblox Space shortcut.
  6. Approve a permission prompt if present, then wait for the viewer to attach.

C. Daily operation and ordinary restarts

Use the top-right Chinese / English selector in the main window to change the interface language without restarting the workspace. First Setup and the installer also provide a language selector. The app remembers your choice for the current Windows user. App controls, status messages, alert settings, and software update dialogs follow this choice. Roblox itself and Windows keep their own language settings.

  1. Connect external power and open the desktop Roblox Space shortcut.
  2. Wait for the workspace picture and enter the game.
  3. Open the screenshot position picker. Select a safe location and confirm it.
  4. Press F6 to start or stop clicking once per second. A fresh application launch requires another position confirmation.
  5. Before using the game keyboard, stop automatic clicking and use the keyboard-input button.
  6. Minimizing leaves the workspace running. X exits the game, clicking, monitor, viewer, and application.

After an ordinary Windows restart, use this sequence. Do not repeat account creation, pairing, or notification binding when the same Windows setup is still intact.

The top status indicators show network state, phone notification state, and cloud notification state. Read yellow messages for missing configuration or verification failures. A healthy internet check does not guarantee a specific game server is available.

On battery, the complete workspace exits. Reconnecting external power keeps it closed until you start it yourself.

D. Phone notifications

D1. Bind your Telegram bot

  1. Open the official BotFather in Telegram. Use /mybots for an existing bot, or /newbot to create one.
  2. Save the full bot token privately. Paste it only into the local notification settings.
  3. Use the connect-bot button. Open the binding link and press Start in Telegram. The current link includes a binding code; an old chat alone does not complete binding.
  4. Return to the application, complete binding, and send a test message.
  5. After receiving the test, save and enable notifications. Valid configured notifications are enabled on later launches.

D2. Configure Healthchecks for complete computer disconnection

A disconnected computer cannot send an immediate Telegram message itself. Healthchecks monitors missing heartbeats from outside the computer.

  1. Sign in to Healthchecks.io. Reuse your existing workspace check or create a new one.
  2. Choose Simple schedule, Period 1 minute, Grace Time 1 minute. Save both values.
  3. Leave Manual Resume off so a heartbeat can resume a paused check.
  4. In the project's Integrations, connect Telegram through the official HealthchecksBot. Start the bot, follow its link, select the project, and connect.
  5. Ensure that Telegram integration is assigned to this specific check.
  6. Copy the complete Ping URL and obtain the full project read-write API key from Settings, API Access.
  7. In the application's notification settings, enter the Ping URL and API key, verify the cloud settings, then save and enable.
The application sends a heartbeat about every 30 seconds. Cloud alerts are expected about two minutes after the last received heartbeat. They do not wait for Roblox to disconnect. The displayed countdown is an estimate; phone delivery is not guaranteed at exactly zero.

D3. Test a real network outage

  1. Keep the application open and the computer on external power. Do not press X: normal exit attempts to pause the cloud check.
  2. Turn off the phone's Wi-Fi and enable mobile data. Confirm Telegram can connect.
  3. Disconnect only the computer's network for at least three minutes. Look for a DOWN alert from HealthchecksBot.
  4. Restore the network and look for UP. Queued messages from your own bot can retry after reconnection.

Test a power change separately from a network outage, because battery mode closes the application.

E. Application software updates

Software updates upgrade Roblox Space itself. Telegram and Healthchecks are configured in the separate notification settings.

The official public update feed is https://raw.githubusercontent.com/jasonhome-344423/roblox-space/main/latest.json. A new installation sets this address automatically. Keep the matching installer and update manifest together when using a local update.

Use a local installer

  1. Keep RobloxSpace-Setup.exe and RobloxSpace-Setup.exe.update.json in the same normal folder.
  2. Open Software Updates, choose the local-installer action, and select the EXE.
  3. If prompted, select the matching JSON. Confirm the trusted source and that the game may close.
  4. The application validates the installer and continues installation for different application content. The same build requires no update; run the EXE directly for repair installation.
  5. Before starting the installer, the application completely exits the workspace. Use the same installation directory.
  6. After installation, open Roblox Space and reconfirm the click position.

Directly running the EXE does not require the JSON. The JSON is needed for importing an installer through Software Updates. Size, SHA256, and product checks verify integrity and product matching; they do not authenticate an unknown publisher.

Enable automatic update reminders

  1. Use the official feed: https://raw.githubusercontent.com/jasonhome-344423/roblox-space/main/latest.json. A repository homepage or EXE URL is not a feed.
  2. Enter that URL in Software Updates, enable automatic checks and reminders, then save.
  3. Use Check Updates to confirm the feed loads. Automatic checks run about every six hours while the application is open.
  4. A reminder does not install by itself. Confirm an installation only when the current game can close.

Versioning starts at 1.0.0: major releases increment the first number, minor releases the second, and bug fixes or patches the third. Beta uses the same base version with a Beta label. Updates also verify installation-content fingerprints.

F. Save before installing Windows again

  1. Keep the full source-and-instructions ZIP on an external drive or a fully synchronized cloud drive outside the disk being formatted. The project source backup is retained locally and is not uploaded to this repository.
  2. Save Roblox and Telegram login methods, bot username and token, Healthchecks login, complete Ping URL, and full read-write API key in your own password manager.
  3. Pause the old computer's Healthchecks check during the Windows installation.
  4. After installing Windows, follow section B and bind notifications again.

Old encrypted notification files depend on the Windows user and cannot be assumed to work on a new system. Source backups exclude passwords, bot tokens, API keys, chat identifiers, and pairing private keys.

The complete local source backup includes build and installer code. Extract the full backup, use its install command to generate an EXE, or use its rebuild command to compile the application and run checks. Windows' built-in .NET Framework compiler is used; no external packaging compiler is required.
