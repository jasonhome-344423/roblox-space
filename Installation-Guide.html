先看：安装 Windows 前保存什么

  1. 把整个源码备份 ZIP 放到 U 盘、外接硬盘或确认上传完成的云盘。不要只放在准备格式化的硬盘。

A　本机升级：原来的空间仍然可用

A1　关闭当前空间，找到安装 EXE

  1. 按当前空间右上角 X，等游戏、监测器与画面退出。安装器遇到仍在运行的空间时，会提示先退出。
  2. 找到本次交付的 RobloxSpace-Setup.exe。它可以独立运行，不必先解压源码备份。
  3. 如果安装 EXE 放在 ZIP 中，先把 EXE 解压到普通文件夹再运行。

完成标志：当前空间已退出，安装 EXE 已保存在普通文件夹。

A2　安装本次正式版

  1. 双击 RobloxSpace-Setup.exe，按向导选择安装位置并点“安装”。默认目录为 %LOCALAPPDATA%\Programs\RobloxSpace。
  2. 升级时继续使用原来的安装目录。安装完成后保留桌面入口 Roblox Space。
  3. 同一个 Windows 用户升级时，已有配对和通知资料会保留；不需要因为本次升级重新配对或创建机器人。
  4. 已有空间能正常使用时，直接打开程序确认。只有缺少配置时才打开“首次配置”，点“重新检查”；不要重复建账户、改密码或安装 Duo。

完成标志：安装向导完成，桌面入口能打开现有空间，通知设置仍在。

A3　打开并确认

  1. 从桌面 Roblox Space 启动，Windows 权限确认选“是”。
  2. 等待画面接入。已有绑定时，顶部显示“手机提醒 · 已开启”和“断网提醒 · 已开启”。
  3. 进入游戏，重新截图选点，再按 F6。迁移不成功时保留旧资料，按 D 节重新绑定。

完成标志：画面可操作、通知状态正常。日常按 C 节使用。

B　新 Windows：按 B1 → B7 完成

B1　准备系统

  1. 使用 Windows 11 64 位。按 Win＋R，输入 winver。Duo 1.6.0 最低要求为 Windows 11 24H2。
  2. 完成 Windows 更新与显卡驱动安装。
  3. 打开“Windows 安全中心 → 设备安全性 → 内核隔离详细信息”，开启内存完整性。需要重启时先保存工作，重启回来确认已开启。
沿用本机已验证设置：内存完整性开启、Process Patching 关闭、HDR 关闭。本机之前出现过与 Duo 内核补丁吻合的蓝屏，不要为 HDR 或高帧率关闭这些保护。

完成标志：系统符合要求，内存完整性正在运行，电脑插电。

B2　运行独立安装程序

  1. 把 RobloxSpace-Setup.exe 保存在普通文件夹，双击运行。
  2. 按向导完成安装。默认安装到当前用户的 %LOCALAPPDATA%\Programs\RobloxSpace，不需要自己复制 DLL。
  3. 安装结束时打开“首次配置”。以后也可从开始菜单“Roblox 空间 → 首次配置”打开。

完成标志：桌面有 Roblox Space，首次配置窗口能打开。继续完成 B3 → B7。

B3　安装 Duo

  1. 在首次配置点“打开 Duo 下载页”，或打开 Duo 1.6.0 官方发布页。
  2. 展开 Assets，下载 Duo.exe，运行并按安装向导完成。
  3. 如果要求重启，保存其他工作后自行完成，再打开首次配置。
  4. 打开 Duo Manager 的设置，关闭 Process Patching，HDR 也保持关闭。

完成标志：首次配置能找到 Duo，Process Patching 关闭。

B4　配置账户、权限和监测任务

  1. 点“配置账户和监测任务”，Windows 权限确认选“是”。
  2. 没有空间账户时，会弹出密码窗口。为 RobloxSpaceBeta 输入两次相同的非空密码并保存，稍后填到 Duo。
  3. 脚本会创建标准账户、配置运行目录权限、部署监测器，并创建计划任务；不会启动游戏。
  4. 看到“配置完成”，回到首次配置点“重新检查”。
正式版继续用内部账户名 RobloxSpaceBeta、Duo 实例名 RobloxBeta，用于兼容已有空间。这不代表安装了另一套测试软件。脚本读取新系统实际 SID，不需要旧电脑 SID，也不会重置已有密码。

完成标志：显示账户、权限和监测任务已配置。若同名任务身份不符，先看 G 节。

B5　建立 Duo 工作区

  1. 点“打开 Duo Manager”。如果已有正确的 RobloxBeta，继续使用。
  2. 新系统点 New instance，按表填写。账户密码使用 B4 保存的密码。
  3. 保存并启动实例。按需要开启 Duo 随 Windows 启动与实例 Auto Start；本程序不会因插电自动重开。

完成标志：RobloxBeta 已启动，字段和表格一致。

B6　Moonlight 配对

  1. 在 Duo 的 RobloxBeta 实例上点 Pair New Client。
  2. 回到首次配置，点“打开 Moonlight 配对”。它会使用正确的专用工作目录。
  3. 在 Moonlight 点添加电脑（＋），填 127.0.0.1:62461。
  4. 点找到的 RobloxBeta，读取本次 PIN，输入 Duo 的配对页面并提交。
  5. 配对成功后，在 Moonlight 打开 Desktop，完成空间里 Windows 的首次登录设置，直到看到新桌面。
  6. 测试鼠标、键盘；完成后关闭临时 Moonlight 窗口，回首次配置点“重新检查”。
从“首次配置 → 打开 Moonlight 配对”进入。不要从其他目录随便双击 Moonlight.exe，否则可能再次提示 has not been paired。每次使用当次 PIN，不能抄旧数字。

完成标志：Moonlight 能打开 Desktop，首次配置找到了配对文件。

B7　在空间内安装 Roblox

  1. 在空间桌面打开浏览器，进入 Roblox 官网，手动登录。
  2. 选择游戏，按官网流程安装 Roblox Player。安装和登录都要在空间账户的桌面内完成。
  3. 测试鼠标、WASD 和聊天。主桌面安装过 Roblox 不等于空间账户也装好。
  4. 回主桌面，关闭临时 Moonlight 窗口，从桌面 Roblox Space 或首次配置“打开 Roblox 空间”启动。
  5. 权限确认选“是”，等待画面接入。第一次建立会比日常启动慢。

完成标志：游戏显示在正式版空间窗口中，可以手动操作。接着按 C 节使用，需要手机通知则做 D 节。

C　日常操作和普通重启

语言切换：在主窗口右上角选择“华语”或“English”，界面立即切换，不需要重启空间；下次打开会记住选择。首次配置、安装程序和卸载程序也能选择语言。通知设置、点击状态、程序弹窗和本程序发出的手机提醒随应用语言变化。源码备份提供华语和英文命令入口。本说明顶部按钮单独切换说明语言。

Roblox、Windows、Duo、Moonlight、Telegram 和 Healthchecks 是独立产品；它们的网页、系统提示、游戏内容和云端自动消息使用各自的语言设置。本程序的语言选择不会更改这些第三方内容，也不会翻译你输入的名称、网址、密码或密钥。

  1. 电脑保持插电。双击桌面 Roblox Space，权限确认选“是”。
  2. 等待画面，进入游戏。
  3. 点“截图选位置”，在截图中选安全位置并确认，不限定聊天按钮。
  4. 按 F6 开启／停止点击，频率每秒一次。每次新启动后重新确认选点。
  5. 要用游戏键盘，先按 F6 停止点击，再点“键盘输入”。
  6. 最小化继续运行；右上角 X 关闭游戏、点击、监测器、Moonlight 画面和本程序，保留 Duo 工作区供下次快速启动。需要连 Duo 一起关闭时，程序开着期间右键任务栏托盘图标，选择“全部退出（包括 Duo）”。
运行中的程序切到电池时，会关闭游戏、点击、监测器、Moonlight、本程序及 Duo；接回电源不会自动重开。普通 X 退出后仍保留 Duo，程序已退出期间不再监测供电变化。需要全部关闭时，退出前使用托盘“全部退出（包括 Duo）”。

电脑刚重启或 Duo 已完全关闭时，需要重新建立工作区，本机以往测试约 20–25 秒；普通 X 后再开会复用工作区，通常较快。耗时随电脑和系统状态变化，不保证固定秒数。

D　手机通知：两部分都要做

D1　自己的 Telegram 机器人

  1. 在 Telegram 打开官方 @BotFather。已有机器人用 /mybots 查看；需要新建才用 /newbot，按提示填名称和以 bot 结尾的用户名。
  2. 复制完整 Bot Token，只粘贴到本机设置，不发到聊天或本说明。
  3. 在空间点“通知设置”，粘贴 Token →“1. 连接机器人”。
  4. 在打开的本次绑定链接里点 Start。链接有绑定码，只打开旧聊天不能替代。
  5. 回设置点“2. 完成绑定”→“发测试到手机”。确认收到了，再点保存并启用。
  6. 资料齐全后每次启动自动开启，不用再勾选。

完成标志：自己的机器人发来测试消息，主窗口显示手机提醒已开启。

D2　完全断网的 Healthchecks 云端提醒

电脑断网后不能自行立刻发消息，所以云端检测心跳中断并通知手机。它和 D1 是两套渠道。

  1. 登录 Healthchecks.io，为本软件新建一个专用项目，该项目只保留「Roblox 空间」这一个检查，不与其他服务共用。已有检查在其他项目时，在检查详情选择 Transfer to Another Project 转入专用项目（Ping URL 可保留），然后在新项目重新配置 Telegram 集成，并使用新项目自己的读写 API Key。不要把包含其他服务的项目 Key 填入本软件，也不要贸然撤销其他服务正在使用的旧 Key。
  2. 类型选 Simple。Period＝1 分钟，Grace Time＝1 分钟，保存并确认两个值。
  3. 过滤规则里，暂停检查收到心跳时允许自动恢复，Manual Resume 关闭。
  4. 在项目 Integrations → Telegram 连接：Telegram 打开 @HealthchecksBot → Start → 点它回复的链接 → 选当前项目 → Connect Telegram。
  5. 回到“Roblox 空间”检查，确认它启用了这个 Telegram 渠道。只连接项目但没分配给检查仍不行。
  6. 复制完整 Ping URL，形如 https://hc-ping.com/一串UUID。
  7. 在项目 Settings → API Access 获取读写 API Key。不是只读 Key，也不是 Bot Token。完整 Key 如果只显示一次，立即保存到自己的密码管理器。
  8. 在本程序“通知设置”填写 Ping URL 和 API Key →“验证云端设置”→ 成功后保存并启用。
程序约每 30 秒发心跳；云端从最后一次收到心跳计算约 2 分钟，不等待 Roblox 掉线。界面是预计倒计时，不保证手机精确在零秒弹出。

D3　怎样做真实断网测试

  1. 程序保持打开、电脑保持插电。不要点 X，正常退出会尝试暂停云端检查。
  2. 手机关闭 Wi-Fi、开启移动数据，确认 Telegram 能联网。
  3. 只断开电脑网络，持续 3 分钟，查看 HealthchecksBot 的 DOWN。
  4. 恢复网络，查看 UP；自己的机器人排队消息也会恢复重试。

完成标志：HealthchecksBot 收到 DOWN／UP。拔电源会退出程序，电池退出测试要与断网测试分开。

E　手动安装程序

F　从源码重建与备用恢复

  1. 把整个源码 ZIP 完整解压到普通文件夹，保留目录结构，不要在 ZIP 预览中运行，也不要只取几个源文件。
  2. 先运行 校验备份.cmd 或 Verify-Backup.cmd，确认校验成功。校验失败时重新完整解压。
  3. 关闭 Roblox Space，双击 重建程序.cmd 或 Rebuild.cmd，命令会同时显示华语和英文结果。
  4. 等待编译、C# 检查和 PowerShell 检查。可能出现短暂测试窗口；保持主桌面，不要同时输入游戏。
  5. 成功后会更新 app、校验清单，并在 outputs\安装程序 生成 RobloxSpace-Setup.exe；双击该 EXE 安装。
可选：在解压根目录打开 Windows PowerShell：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\source\Build.ps1

G. Troubleshooting and final checks

Computer has not been paired

Close Roblox Space and temporary Moonlight windows. Use First Setup's pairing button and repeat B6 with the current PIN and dedicated working directory. Do not delete certificates at random or disable security features.

No workspace picture or startup does not finish

Confirm external power, a running RobloxBeta instance, the correct account password, and port 62461. Keep Process Patching and HDR off and Memory integrity on. First test whether Moonlight can open Desktop, then start Roblox Space. Use First Setup's Recheck to locate missing setup.

Access denied, monitor missing, or task not found

Exit completely, then use First Setup's Configure account and monitor task and approve UAC. It uses the current SID. The task is Codex-RobloxSpace-Worker, for RobloxSpaceBeta, interactive login, ordinary permissions; program C:\ProgramData\RobloxSpace\RobloxSpaceWorker.exe; argument --start-monitor; no scheduled triggers and no highest-privilege setting. An existing task with a different identity is not overwritten. Check it first and do not delete unrelated tasks.

Clicking or keyboard does not respond

Join a game, enable monitoring, and confirm the screenshot position. The click area shows the current blocking reason. Before typing, stop clicking with F6 and select Keyboard input. Confirm a new position after a resolution change; the old position will not continue blindly.

No phone message

Keep the application running, check the top status, and confirm phone internet and Telegram notification permission. A normal test uses your own bot; a complete-outage test uses HealthchecksBot. Disconnect for three minutes; exiting the application is not an outage test. Check that Telegram is assigned to this specific cloud check.

Installer says the application is still running

Use X, wait for the game, monitor, and viewer to exit, then continue the installer. Minimizing is not an exit. Follow the specific displayed error if a component or permission problem remains.

Recovery command reports a directory or checksum error

Use the default dedicated installation directory and extract the complete source backup first. Notification status and diagnostic logs

Connection timed out, retrying means the computer did not receive Telegram's response in time. The application rechecks after about 30 seconds without requiring another binding. Requests canceled during shutdown are handled separately from network timeouts.

  1. Use desktop Roblox Space for daily operation. Keep internal account RobloxSpaceBeta and Duo instance RobloxBeta; these compatibility names are not unused test software.
  2. After launch, read the Phone alerts and Outage alerts cards. Telegram is checked every minute in the background, cloud heartbeats are sent every 30 seconds, and channel settings are checked every minute.
  3. Connection pending means the latest successful result is not recent enough. Rechecking is automatic; it does not mean the token expired. For Bot verification failed, check the network, then the saved token in Notification settings.
  4. Normal exit attempts to pause the cloud check, and launching again resumes heartbeats. Outages are not monitored while the application is closed.
  5. The primary log is %LOCALAPPDATA%\RobloxSpace\entry-launch.log. If it cannot be written, the application tries %LOCALAPPDATA%\RobloxSpaceLogs\entry-launch.log, then C:\ProgramData\RobloxSpace\entry-launch.log if both user paths fail.
