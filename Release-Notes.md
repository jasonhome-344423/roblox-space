# Roblox Space

- The Windows release uses a native C++ host, an elevated workspace manager, and a separate worker for Roblox input, monitoring, and reconnects.
- Clicking X closes the workspace game, worker, Moonlight viewer, and Duo. The window hides while the application verifies shutdown. The tray has a separate option to keep Duo running.
- The installer and offline installation guide support English and Chinese.

Download **RobloxSpace-Setup.exe** and verify its SHA256 using **SHA256SUMS.txt** from this release. On a new Windows installation, use **Installation-Guide.html** to configure Duo, pairing, and Roblox. Third-party notices and corresponding sources are in **Third-Party-Notices.zip**.
